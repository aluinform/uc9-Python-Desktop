Para centralizar a janela no Tkinter, você precisa calcular o tamanho da tela do usuário e ajustar
as coordenadas (X e Y) na função geometry.

Você deve substituir a linha self.root.geometry("350x250") dentro do método __init__ pelo código
abaixo:

        # Definir largura e altura da janela
        largura = 350
        altura = 250

        # Obter a largura e altura da tela do sistema
        largura_tela = self.root.winfo_screenwidth()
        altura_tela = self.root.winfo_screenheight()

        # Calcular as posições X e Y para centralizar
        pos_x = (largura_tela // 2) - (largura // 2)
        pos_y = (altura_tela // 2) - (altura // 2)

        # Aplicar as dimensões e o posicionamento
        self.root.geometry(f"{largura}x{altura}+{pos_x}+{pos_y}")
